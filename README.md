# HiQS Labs welcome page

This repository publishes the organization home page at <https://hiqs-labs.github.io/> using GitHub Pages from the root of `main`.

`index.html` is a static directory of the public HiQS Labs repositories. The XYZ Forge link intentionally points to its [hosted project page](https://hiqs-labs.github.io/XYZ-forge/). When adding or retiring a public repository, update the links here; the “Browse every repository” link always leads to the live organization list.
